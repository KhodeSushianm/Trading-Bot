# 🎨 سیستم طراحی رابط — تم روشن شیشه‌ای (Glassmorphism) نسخه ۰٫۶

> بازطراحی کامل بر پایهٔ زبان داشبوردهای مدرن ۲۰۲۶ (الگو: رفرنس iDraft):
> پس‌زمینهٔ خاکستریِ محو + پنل شیشه‌ای، سایدبارِ **کارت شناور سفید** با آیتم فعال
> به‌شکل **پیِل مشکی**، **کارت‌های مشکیِ پرکنتراست** در کنار کارت‌های سفید با سایهٔ نرم،
> گوشه‌های خیلی گرد، دکمه‌های دایره‌ای، نمودار خطی و حلقهٔ پیشرفت.
>
> قانون رنگ همچنان مونوکروم است: سیاه/سفید/خاکستری + فقط **سبز** (خرید/موفقیت)
> و **قرمز** (فروش/وتو/خطا).

![داشبورد](images/panel-dashboard.png)

## ۱. توکن‌های رنگ (`src/ui/theme.py`)

| نقش | کد |
|---|---|
| پس‌زمینهٔ محو | `#E7E7EC` |
| لایهٔ شیشه | سفید با آلفای ۰٫۵۵ |
| کارت سفید | `#FFFFFF` |
| کاشی/ورودی روشن | `#EDEDF0` / `#FAFAFC` |
| **کارت مشکی (لهجه)** | `#101013` |
| کاشی داخل کارت مشکی | `#26262B` |
| مرز موئی | `#E3E3E8` |
| جوهر (متن) | `#0B0B0C` / `#55555E` / `#94949C` |
| سبز معنایی | `#1F9D66` |
| قرمز معنایی | `#D64545` |

شعاع‌ها: کارت `22px` · کنترل `12px` · پیِل/دایره `999px` · سایدبار `26px` · شیشه `30px`.

### چرا «شفافیت/بلور واقعی» نه؟
بلور زنده (`QGraphicsBlurEffect`) روی کانتینر همان خانواده باگی است که قبلاً
«صفحه سیاه تا درگ» را ساخت. پس:
- پس‌زمینه از **گرادیان‌های شعاعیِ ذاتاً نرم** ساخته و یک‌بار کش می‌شود (`backdrop.render_backdrop`)
- شیشه یک لایهٔ سفید نیمه‌شفافِ ساده است (`backdrop.paint_glass`)
- **صفر اثر گرافیکی** در کل رابط

## ۳. چیدمان

```
┌─ شیشه ────────────────────────────────────────────────────────┐
│ هدر: سلام {نام}! + زیرعنوان      [پیِل مشکی شروع] (○)(○)(○) 🕒 (آواتار) │
│ ┌─ سایدبار شناور ─┐  ┌─ محتوا ────────────────────────────────┐ │
│ │ منو             │  │ داشبورد                                │ │
│ │  ● داشبرد (پیِل) │  │ [کارت مشکی نمای کلی][نمودار خطی][حلقه] │ │
│ │  ○ سیگنال‌ها     │  │ [سیگنال‌های اخیر + خط‌چین][چک‌لیست]     │ │
│ │  ○ گزارش کامل   │  │ رویدادهای پیش‌رو                        │ │
│ │  ○ تقویم/اخبار  │  │ [کارت مشکی][کارت مشکی][کارت مشکی]       │ │
│ │  ○ بریفینگ      │  │                                        │ │
│ │ ── سیستم ──     │  │                                        │ │
│ │  ○ گزارش زنده   │  │                                        │ │
│ │  ○ تنظیمات      │  │                                        │ │
│ └─────────────────┘  └────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────┘
```

- سایدبار یک **کارت شناور** است (نه نوار چسبیده به لبه)؛ گروه «سیستم» با
  stretch به پایین کارت می‌رود (مثل Settings رفرنس).
- آیتم فعال = **پیِل مشکی** با متن/آیکون سفید؛ بقیه خاکستری.
- کارت مشکی «نمای کلی» شامل قرص وضعیت، دو عدد بزرگ، و سه کاشی خاکستری است
  (معادل 43/2 و 28/14/11 رفرنس).
- رویدادهای پیش‌رو به‌شکل **کارت‌های مشکی** ردیف می‌شوند (معادل Last Projects).
- جای خالی سیگنال = **کارت خط‌چین** «+ منتظر سیگنال بعدی» (معادل + Add task).

## ۴. اجزای اختصاصی (`src/ui/widgets.py`)

## ۶. حرکت (Motion)

ظریف و حرفه‌ای؛ هیچ‌کدام بلوکه‌کننده نیست و همه ≤ ۳۲۰ms:
Splash (ورود پلکانی + خط پیشرفت + محو) · fade پنجره و صفحه‌ها · fade کارت‌ها هنگام
تعویض · نقطهٔ تپندهٔ وضعیت · Toast اسلاید از بالا · درخشش ۶ ثانیه‌ای آیتم ناوبری.
با `ui.animations: false` همه آنی می‌شوند.

## ۱۰. دو قید سخت که از دل باگ‌ها بیرون آمد (این‌ها را نشکن)

۱) **هیچ `QGraphicsOpacityEffect` نباید بعد از انیمیشن باقی بماند** — وگرنه
   Qt فرزندان را در بافر آف‌اسکرین نگه می‌دارد و update()ها repaint نمی‌شوند
   («صفحه سیاه تا درگ»). `effects.fade()` همیشه اثر را حذف می‌کند و
   `panel.py --selftest` + `tests/manual/test_pages_render.py` همین را assert می‌کنند.
۲) **`QPlainTextEdit` هرگز `background-color: transparent` نگیرد** — با پس‌زمینهٔ
   شفاف متن تا اولین repaint کامل رسم نمی‌شد. نمای `#plain` پس‌زمینهٔ solid دارد.

## ۱۲. درس‌های رندر کراس‌پلتفرمی (از باگ‌های گزارش‌شدهٔ ویندوز، v0.7.2)

اسکرین‌شات کاربر روی ویندوز (DPI ۱۲۵٪، اندازهٔ منطقی ~۱۵۳۵×۸۶۳) هفت خانواده باگ
ظاهری داشت که همه رفع و با `tests/manual/test_layout_fit.py` قفل شدند:

۱) **سرریز چیدمان در پنجرهٔ کوچک** — حلقه و نمودار بیرون کارت نقاشی می‌شدند.
   `RingGauge` حالا اندازهٔ منعطف ۸۴ تا ۲۲۰ دارد، `LineChart` حداقل ارتفاع ۹۲ و
   سیاست `Expanding`، و کل صفحهٔ داشبورد داخل `QScrollArea#pagescroll` است
   (عمودی آزاد، افقی هرگز). برچسب‌های محور نمودار در عرض کم یکی‌درمیان می‌شوند
   تا همپوشانی نکنند.
۲) **متن نامرئی روی کارت مشکی** — QSS رنگ را به برچسب‌های فرزند القا نمی‌کند و
   روی بعضی پلتفرم‌ها اصلاً اعمال نمی‌شد (سیاه روی سیاه). قانون جدید: رنگ متن
   هر برچسب داخل `InkCard` **در کد** ست می‌شود (`setStyleSheet`)، نه فقط با
   objectName. `StatusPill` هم پارامتر `onink=True` گرفت و رنگ متن حالت‌ها در کد است.
۳) **ارقام فارسی با فونت mono نشکن است** — `font-family`_mono برای ساعت/اعداد
   بزرگ حذف شد؛ Vazirmatn گلیف فارسی دارد و mono نه (حداقل روی ویندوز).
۴) **ایموجی ممنوع** — نقطه‌های اثر رویداد (🔴/🟠) هم پالت را می‌شکستند هم روی
   همهٔ دستگاه‌ها یکسان رندر نمی‌شدند؛ حالا نقطه با `_dot_pixmap()` در کد نقاشی
   می‌شود: قرمز معنایی برای «پراثر»، خاکستری روشن برای «متوسط».
۵) **دقیقهٔ خام ممنوع** — «۲۵۱ دقیقهٔ دیگر» خوانا نیست؛ `src/fa.py::fa_countdown`
   زمان را انسانی می‌کند: دقیقه / ساعت و دقیقه / روز.
۶) **«+» کارت خط‌چین** — با نشانهٔ `\u200F` اولِ عبارت در چیدمان RTL می‌ماند.

تست نگه‌داشت (`test_layout_fit.py`) در سه اندازه (۱۵۳۵×۸۶۳، ۱۰۲۰×۷۰۰، ۱۹۲۰×۱۰۸۰)
assert می‌کند: هیچ فرزندی بیرون مستطیل کارت میزبانش نیست، همهٔ متن‌های روی کارت
مشکی روشن‌اند، و اسکرول افقی داشبورد هرگز فعال نمی‌شود.
