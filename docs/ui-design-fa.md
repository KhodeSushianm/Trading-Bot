# 🎨 سیستم طراحی رابط — تم مونوکروم تاریک (نسخه ۰٫۵)

> بازطراحی کامل پنل بر پایهٔ زبان **Fluent / ویندوز ۱۱** با یک محدودیت سخت:
> **همه‌چیز سیاه و سفید.** تنها دو رنگ معنایی مجازند — سبز و قرمز.
> این سند توضیح می‌دهد *چرا* هر تصمیم گرفته شده، تا دفعهٔ بعد کسی تصادفی رنگ اضافه نکند.

![داشبورد](images/panel-dashboard.png)

---

## ۱. قانون رنگ (مهم‌ترین قاعده)

| نقش | رنگ | کد |
|---|---|---|
| پس‌زمینهٔ پایه | سیاهِ بسیار تیره (نه مطلق) | `#0B0B0D` |
| سطح کارت | | `#151519` |
| سطح برجسته (ورودی/دکمه ثانویه) | | `#202026` |
| مرز موئی | | `#26262C` |
| متن اصلی | سفیدِ نزدیک به خالص | `#F4F4F7` |
| متن ثانویه | | `#9E9EA8` |
| متن سوم/غیرفعال | | `#63636D` |
| **سبز** = خرید / موفقیت / در حال اجرا | | `#3ECF8E` |
| **قرمز** = فروش / وتو / خطا | | `#FF5D5D` |

**هیچ رنگ سومی وجود ندارد.** نه آبی برای لینک، نه کهربایی برای هشدار، نه بنفش.
«احتیاط» با آیکون ⚠ و وزن متن متمایز می‌شود، نه با رنگ جدید.

### چرا سیاهِ مطلق (`#000`) نه؟
روی نمایشگرهای OLED هاله (smear) می‌سازد و کنتراست متن سفید رویش برای خواندن
طولانی خسته‌کننده است. ویندوز ۱۱ و Fluent هم از سیاهِ ته‌رنگ‌دار استفاده می‌کنند.

### عمق بدون سایه
به‌جای سایهٔ سنگین (که در تم تیره گِل‌آلود می‌شود)، عمق با **روشنیِ تدریجی سطح**
ساخته می‌شود: پس‌زمینه ← کارت ← برجسته. به‌علاوه مرزهای موئی ۱px.

## ۲. تایپوگرافی

فونت: **وزیرمتن** (همراه برنامه) با اولویت ایران‌سنس اگر کاربر گذاشته باشد.

| نقش | اندازه | وزن |
|---|---|---|
| نام کاربر در Splash | 30 | 800 |
| عنوان صفحه | 20 | 700 |
| عنوان کارت | 14 | 700 |
| متن اصلی | 13 | 400 |
| برچسب/راهنما | 11 | 400 |
| عدد بزرگ کارت آمار | 26 | 700 (مونواسپیس) |

اعداد و قیمت‌ها با فونت مونواسپیس (`Cascadia Mono / Consolas`) تا ستون‌ها زیر هم تراز بمانند.

### قانون ارقام
- شمارش‌ها، امتیازها، پیپ، درصد → **ارقام فارسی** (۰-۹)
- **قیمت‌ها → ارقام لاتین**، چون کاربر آن‌ها را در پلتفرم معاملاتی تایپ می‌کند
  و کپی/پیستِ ارقام فارسی خطا می‌دهد
- نام اندیکاتورها (`ADX=39`) → لاتین، مطابق سبک گزارش تکنیکال

## ۳. چیدمان

```
┌────────────────────────────────────────────────────────┐
│ هدر: لوگو + نام + چیپ «خوش اومدی …» + ساعت             │
├──────────┬─────────────────────────────────────────────┤
│          │  عنوان صفحه + اقدام‌ها                       │
│  ریل     │ ┌─────────────────────────────────────────┐ │
│  ناوبری  │ │ کارت وضعیت (قرص وضعیت + وتو)             │ │
│  (آیکون  │ ├──────┬──────┬──────┬──────┤               │
│  + برچسب)│ │ آمار │ آمار │ آمار │ آمار │               │
│          │ ├──────┴──────┴──────┴──────┤               │
│          │ │ دو ستون: سیگنال‌ها / رویدادها             │ │
│          │ ├─────────────────────────────────────────┤ │
│          │ │ نمودار جریان قدرت ارزها                   │ │
│          │ └─────────────────────────────────────────┘ │
└──────────┴─────────────────────────────────────────────┘
```

- **ریل ناوبری عمودی** (در RTL سمت راست) با آیکون برداری + برچسب + **نشانگر سفید متحرک**
  کنار آیتم فعال. جایگزین تب‌بار افقی قدیمی شد.
- **۷ صفحه**: داشبورد · سیگنال‌ها · گزارش کامل · تقویم و اخبار · بریفینگ · گزارش زنده · تنظیمات
- تنظیمات تلگرام از صفحهٔ اصلی به **صفحهٔ تنظیمات** منتقل شد تا داشبورد خلوت بماند.
- گوشه‌ها: کارت `14px`، کنترل `9px`، قرص/چیپ کاملاً گرد.

## ۴. آیکون‌ها

۲۶ آیکون **SVG خطی** (stroke ≈۱.۶px، گوشه گرد) در `src/ui/icons.py`.
رندر با QtSvg و کش بر اساس (نام، اندازه، رنگ).

چرا نه ایموجی؟ ایموجی در ویندوز با Segoe UI Emoji **رنگی** رندر می‌شود و با یک تم
مونوکروم می‌جنگد؛ ضمن اینکه در بعضی سیستم‌ها اصلاً گلریف ندارند. آیکون خطی رنگش را
از توکن تم می‌گیرد و در هر اندازه شارپ می‌ماند.

اگر QtSvg به هر دلیلی نبود، به یک گلیف متنی fallback می‌شود تا رابط هرگز بی‌آیکون نماند.

## ۵. حرکت (Motion)

انتخاب: **ظریف و حرفه‌ای**. هیچ انیمیشنی بیشتر از ~۳۲۰ms و هیچ‌کدام بلوکه‌کننده نیست.

| کجا | چه |
|---|---|
| Splash | ورود پلکانی اجزا (stagger) → پر شدن خط پیشرفت → محو شدن کل پنجره |
| پنجرهٔ اصلی | fade-in بعد از Splash |
| تعویض صفحه | fade ~۲۲۰ms |
| نشانگر ناوبری | اسلاید عمودی نرم (InOutCubic) |
| وضعیت «در حال اجرا» | نقطهٔ تپنده (هالهٔ بزرگ‌ونده و کم‌رنگ‌شونده، ۱.۶s حلقه) |
| کارت‌های داشبورد | ورود از کمی پایین‌تر + fade، پلکانی |
| سیگنال جدید | Toast از بالا slide-in، خودکار بعد از ~۴s جمع می‌شود |
| محتوای جدید یک صفحه | آیتم ناوبری‌اش ۶ ثانیه قرمز می‌درخشد (badge) |

منحنی استاندارد: `OutCubic` برای ورود، `InOutCubic` برای جابه‌جایی.

## ۶. Splash — «خوش اومدی سوشیان»

![Splash](images/splash.png)

- کارت سیاه گرد در مرکز، لوگو → نام کاربر (۳۰px) → زیرعنوان → خط پیشرفت نازک → نسخه
- نام از `config.yaml` (`ui.user_name`) می‌آید — **هاردکد نیست**
- با `ui.splash: false` یا `--no-splash` غیرفعال می‌شود
- **تزئینی است**: اگر ساختش به هر دلیلی شکست بخورد، برنامه بدون آن بالا می‌آید
  (try/except دورش هست)

## ۷. یکپارچگی با ویندوز ۱۱ (`src/ui/dwm.py`)

روی ویندوز، سه اثر بومی اعمال می‌شود:
1. نوار عنوان تیره (`DWMWA_USE_IMMERSIVE_DARK_MODE`)
2. پس‌زمینهٔ **Mica** (`DWMWA_SYSTEMBACKDROP_TYPE`)
3. گوشه‌های گرد پنجره (`DWMWA_WINDOW_CORNER_PREFERENCE`)

همه داخل `try/except`: روی ویندوز قدیمی، لینوکس یا مک هیچ اتفاقی نمی‌افتد و
رابط با QSS خودمان درست کار می‌کند. این لایه **تزئینی** است، نه کارکردی.

## ۹. دسترسی‌پذیری و خوانایی

- کنتراست متن اصلی روی پس‌زمینه ≈ ۱۵:۱ (خیلی بالاتر از حداقل WCAG AA)
- متن ثانویه ≈ ۷:۱، متن سوم ≈ ۳.۶:۱ (فقط برای برچسب‌های غیرحیاتی)
- ارتفاع حداقل دکمه ۳۸px و آیتم ناوبری ۴۰px — هدف لمسی/ماوس راحت
- سبز/قرمز تنها جایی استفاده می‌شوند که **معنا** دارند؛ کاربر کوررنگ هم با
  آیکون و متن (خرید/فروش، ▲/▼ در گزارش) جهت را می‌فهمد
- انیمیشن‌ها با `ui.animations: false` قابل خاموش‌کردن‌اند (برای کاهش حواس‌پرتی)

## ۱۰. دو قید سخت که از دل باگ‌ها بیرون آمد (این‌ها را نشکن)

۱) **هیچ `QGraphicsOpacityEffect` نباید بعد از پایان انیمیشن باقی بماند.**
   اگر اثر روی ویجت بماند، Qt فرزندان را در بافر آف‌اسکرین رندر می‌کند و
   `update()`های بعدی (تیک هر ثانیه، متن جدید) روی بعضی پلتفرم‌ها repaint
   نمی‌شوند → صفحه سیاه/کهنه می‌ماند تا کاربر درگ یا resize کند.
   به همین دلیل `effects.fade()` همیشه در پایان، اثر را حذف می‌کند و
   `panel.py --selftest` و `tests/manual/test_pages_render.py` همین را assert می‌کنند.

۲) **`QPlainTextEdit` هرگز `background-color: transparent` نگیرد.**
   با پس‌زمینهٔ شفاف، متن تا اولین repaint کامل رسم نمی‌شد (همان symptom).
   نمای `#plain` پس‌زمینهٔ solidِ ظریف (`bg_alt`) + مرز موئی دارد.

## ۱۱. اگر خواستی تغییری بدهی

- رنگ/فاصله/اندازه → فقط در `src/ui/theme.py` (توکن‌ها). هیچ رنگ هاردکد شده‌ای
  نباید جای دیگری باشد.
- آیکون جدید → یک ورودی به `ICONS` در `src/ui/icons.py` اضافه کن (بدنهٔ SVG، viewBox ۲۴).
- صفحهٔ جدید → یک `_page_*` در `panel.py` + یک `nav.add_item(...)`. ترتیب ایندکس‌ها
  در `TAB_*` باید با ترتیب ناوبری یکی بماند (تست خودکار همین را چک می‌کند).
