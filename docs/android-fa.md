## معماری (و چرا این‌طور است)

```
┌────────────────────────────── APK ──────────────────────────────┐
│  MainActivity (Java) — WebView تمام‌صفحه (رابط)                  │
│  OdinService (Java) — سرویس پیش‌زمینهٔ «رصد بازار» (v0.13.0):    │
│    WebView بی‌سر با همان assets/www در حالت ?svc=1               │
│    زمان‌بندی چرخه‌ها: Handler نیتیو (نه تایمر JS)                │
│  BootReceiver — بازگرداندن رصد بعد از ریستارت گوشی              │
│  Bridge (Java) — پل نیتیو (رابط + سرویس):                       │
│    • HTTP (بدون CORS) → Yahoo/TradingView/ForexFactory/RSS      │
│    • SharedPreferences → ژورنال append-only، تنظیمات، کش        │
│      (مشترک بین رابط و سرویس — ضداسپام یکسان، دادهٔ واحد)        │
│    • اعلان‌ها: سیگنال/خبر فوری + اعلان ماندگار رصد               │
│  assets/www (HTML/CSS/JS) — کل منطق و ظاهر:                     │
│    fa · icons · license · config · indicators · session ·       │
│    technical · calendar · news · judge · journal · data ·       │
│    briefing · ui · app                                          │
└──────────────────────────────────────────────────────────────────┘
```

* **چرا WebView + پل نیتیو؟** کل منطق تحلیل یک‌بار با JS بازنویسی شد و
  `Bridge.http` مشکل CORS را دور می‌زند؛ نتیجه: APK سبک (~۱MB)، بدون هیچ
  وابستگی (بدون AndroidX!) و ظاهری دقیقاً یکدست با تم دسکتاپ.
* **منبع داده‌ها همان‌های دسکتاپ‌اند:** Yahoo Finance (کندل‌ها)، اسکنر
  تریدینگ‌ویو (تاییدیه)، فید هفتگی ForexFactory (تقویم)، RSS فارکس (اخبار).
  هیچ کلید API لازم نیست.
* **همه‌چیز روی گوشی محاسبه می‌شود** — هیچ سرور میانی در کار نیست.

## برابری با موتور پایتون (تست parity)

موتور JS **پورت خط‌به‌خط** ماژول‌های پایتون است و با تست خودکار سنجیده می‌شود:

```bash
python tests/js/gen_fixtures.py   # دادهٔ زنده ضبط + محاسبه با موتور پایتون
node tests/js/run_parity.js       # مقایسهٔ خروجی JS با پایتون
node tests/js/smoke_about.js      # دودِ «دربارهٔ ما» (حق نشر/امضا/بدون ایموجی)
node tests/js/smoke_icons.js      # دودِ آیکون‌ها: ۱۶ رندر، صفر ایموجی (v0.13.0)
node tests/js/smoke_license.js    # دودِ لایسنس: HMAC مشترک با پایتون + قفل دستگاه
node tests/js/smoke_service.js    # دودِ رصد پس‌زمینه: حالت سرویس end-to-end (فاز ۰: گیت لایسنس)
```

۲۴ تست: اندیکاتورها (با لبه‌های NaN دقیقاً مطابق `pandas ewm`)، سشن‌ها،
پارس Yahoo و باز نمونه‌گیری H4، تحلیل تکنیکال، قدرت ارزها، تقویم، تریدینگ‌ویو،
پارس/امتیازدهی اخبار، `news_supports`، **داور کامل در دو زمان** (اکنون +
شبیه‌سازی وسط هفته با سیگنال واقعی)، ژورنال و آمار. هر خروجی عددی و هر
رشتهٔ فارسی (شامل گردش «نصف به زوج» پایتون) مقایسه می‌شود.

### دو تفاوت صادقانه با دسکتاپ
1. **شمارش خرید/فروش تریدینگ‌ویو:** API رسمی دیگر این ستون‌ها را برنمی‌گرداند
   (null). اپ موبایل به‌جای عدد ساختگی، تفکیک MA/نوسان‌گرها را نشان می‌دهد؛
   ملاک امتیاز (خودِ `Recommend.All`) سر جایش است.
2. **تلگرام عمداً port نشد** — کانال اطلاع‌رسانی موبایل، اعلان اندروید است
   (سیگنال تازه/خبر فوری با لرزش). حلقهٔ خودکار از v0.13.0 روی موبایل هم
   هست: «رصد پس‌زمینه» چرخه‌ها را بدون باز بودن اپ تکرار می‌کند و خاموش‌کردنی
   است؛ ولی مثل دسکتاپ **هیچ معامله‌ای اجرا نمی‌شود**. کنترل اسپم سیگنال
   (cooldown سه‌ساعته) دقیقاً مثل دسکتاپ کار می‌کند و بین رابط و سرویس
   مشترک است.

پیش‌نیاز: JDK 17 + اندروید SDK (پلتفرم ۳۴ و build-tools 34).

```bash
cd android
./make-keystore.sh          # یک‌بار — کلید امضا + keystore.properties
gradle assembleRelease      # یا ./gradlew بعد از ساخت wrapper
# خروجی: app/build/outputs/apk/release/app-release.apk
```

⚠️ **`keystore/sushian-khoshkhani-release.jks` و `keystore.properties` را نگه دارید** (در گیت
ثبت نمی‌شوند). به‌روزرسانی اپ باید با همین کلید امضا شود، وگرنه اندروید آن را
«اپ متفاوت» می‌شناسد و ژورنال/تنظیمات با حذف نصب از بین می‌رود.
کلید جاری از v0.13.0 با هویت **Sushian Khoshkhani** و اثر انگشت
`bd11159e003b55b9ae53cd26c192dc6b2bea2840c787fddbd0f523a947cb5189` است
(کلید v0.12.0 گم شد و کلیدهای قدیمی‌تر `sushian-release.jks` مربوط به v0.11.0
و `odin-release.jks` مربوط به ۰.۹/۰.۱۰ فقط برای اعتبارسنجی همان نسخه‌ها
نگه داشته می‌شوند). **از کلید جاری نسخهٔ پشتیبانِ بیرون از این پوشه بگیرید.**

## نصب روی گوشی

1. فایل `ODIN-Assistant-android-v0.14.2.apk` را روی گوشی کپی کنید.
2. رویش بزنید و «Install unknown apps» را برای مرورگر/فایل‌منیجر مجاز کنید.
   (امضای کلید شخصی به نام Sushian Khoshkhani دارد، نه Play Store — طبیعی است.)
3. اگر نسخهٔ ۰.۱۲.۰ یا قدیمی‌تر نصب است: اول ژورنال را «ذخیره در
   دانلودها» بگیرید، نسخهٔ قبل را **حذف نصب** کنید (کلید امضای v0.13.0 عوض
   شده)، بعد این نسخه را نصب کنید. (ارتقا از ۰.۱۳ به ۰.۱۴ درجا است.)
4. اپ را باز کنید — خوش‌آمدگویی: سلب‌مسئولیت ← **فعال‌سازی با کلید لایسنس**
   (کد دستگاه را برای سازنده بفرستید و کلید را وارد کنید) ← اسمتان ←
   پیشنهاد «رصد پس‌زمینه» — و اولین تحلیل خودکار اجرا می‌شود.

حداقل اندروید: **7.0 (API 24)**. پرتره، RTL، فونت وزیرمتن همراه اپ است.

## حریم خصوصی

* هیچ داده‌ای به هیچ سروری جز منابع عمومی داده (Yahoo/TradingView/
  ForexFactory/فیدهای خبری) نمی‌رود.
* ژورنال و تنظیمات فقط در حافظهٔ خصوصی اپ روی خود گوشی است؛ «ذخیره در
  دانلودها» هم فقط یک فایل محلی روی خود گوشی می‌سازد.
* **لایسنس (v0.14.0) کاملاً آفلاین است:** فعال‌سازی هیچ تماس شبکه‌ای
  نمی‌گیرد و هیچ داده‌ای از دستگاه به سازنده نمی‌رود — کاربر خودش «کد
  دستگاه» (هشِ شناسهٔ سیستم) را دستی برای سازنده می‌فرستد.
* **رصد پس‌زمینه (v0.13.0):** فقط وقتی فعال است که خودتان در خوش‌آمدگویی یا
  تنظیمات روشنش کرده باشید؛ در آن حالت یک اعلان ماندگار «در حال رصد بازار»
  نشان داده می‌شود (بدون اعلان پنهان ممکن نیست — الزام اندروید) و دکمهٔ
  «توقف رصد» دارد. دسترسی «شروع مجدد بعد از بوت» فقط برای برگرداندن همان
  رصدِ فعال‌شده توسط خودتان است. اجازهٔ «نادیده‌گرفتن بهینه‌سازی باتری»
  اختیاری است و فقط از دیالوگ رسمی خود اندروید خواسته می‌شود.
* دسترسی‌ها: اینترنت + **اعلان** (اختیاری، برای سیگنال جدید/خبر فوری — اگر
  رد کنید اپ با Toast کار می‌کند) + لرزش + سرویس پیش‌زمینه (رصد) + شروع
  بعد از بوت (اختیاری/خودکار فقط اگر رصد فعال باشد) + در اندروید ۹ و
  قدیمی‌تر، حافظهٔ خارجی فقط برای ذخیرهٔ خروجی ژورنال. هیچ دسترسی حساس
  دیگری (موقعیت، مخاطبین، میکروفون و...) خواسته نمی‌شود.
