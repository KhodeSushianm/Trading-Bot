# 🧪 راهنمای تست مرحله ۱ روی کامپیوتر شما (ویندوز)

این راهنما را قدم‌به‌قدم انجام بده — کل فرایند حدود ۱۰ دقیقه طول می‌کشد.

---

## قدم ۰ — پیش‌نیاز: نصب پایتون

1. برو به [python.org/downloads](https://www.python.org/downloads/) و آخرین نسخه Python 3 را برای ویندوز دانلود کن
2. موقع نصب، **حتماً تیک `Add python.exe to PATH` را بزن** (پایین پنجره نصب) ← بعد Install
3. تست: کلید `Win + R` → بنویس `cmd` → Enter → در پنجره سیاه بنویس:
   ```
   python --version
   ```
   باید چیزی مثل `Python 3.12.x` نشان بدهد.
   > اگر خطای «not recognized» داد، پایتون را دوباره نصب کن و این بار تیک PATH را بزن (یا به‌جای `python` از `py` استفاده کن).

---

## قدم ۱ — دانلود پروژه

**راه ساده (بدون Git):**
1. برو به `https://github.com/KhodeSushianm/Trading-Bot`
2. دکمه سبز **Code** ← **Download ZIP**
3. فایل ZIP را در یک مسیر ساده Extract کن، مثلاً: `C:\Trading-Bot`
   > ⚠️ مسیر پوشه فارسی یا خیلی عمیق نباشد (مثلاً داخل Desktop مشکلی ندارد)

**راه حرفه‌ای (با Git):** اگر Git نصب داری:
```
git clone https://github.com/KhodeSushianm/Trading-Bot.git
```

---

## قدم ۲ — نصب کتابخانه‌ها

در cmd (یا PowerShell) برو داخل پوشه پروژه و کتابخانه‌ها را نصب کن:

```
cd C:\Trading-Bot
pip install -r requirements.txt
```

صبر کن تا تمام شود (یک‌بار بیشتر لازم نیست).

---

## قدم ۳ — اجرای تست با داده Yahoo

```
python main.py
```

بعد از ۱۰ تا ۳۰ ثانیه باید **گزارش فارسی کامل هر ۷ نماد** را ببینی:
قیمت فعلی، جهت روند ۴ ساعته، قدرت روند (ADX)، مومنتوم (RSI)، حمایت/مقاومت، نوسان (ATR)، جمع‌بندی، و در آخر رتبه‌بندی قدرت ارزها.

> 📅 **نکته:** شنبه و یکشنبه بازار فارکس تعطیل است — داده‌ها مربوط به بسته‌شدن بازار در جمعه‌شب خواهند بود. این طبیعی است و نشانه خرابی نیست.
>
> ⚠️ اگر دانلود از Yahoo ناموفق بود (احتمال محدودیت منطقه‌ای روی اینترنت ایران)، نگران نباش — مستقیم برو **قدم ۴** (MT5 منبع داده اصلی و مطمئن‌تر است).

---

## قدم ۴ — اجرای اصلی با داده MT5 خودت (پیشنهاد ما) ✅

این حالتی است که در نسخه نهایی استفاده می‌شود: داده دقیق، مستقیم از بروکر خودت، رایگان.

1. نصب پکیج MT5 برای پایتون:
   ```
   pip install MetaTrader5
   ```
   > فقط روی ویندوز ۶۴ بیتی کار می‌کند.

2. **ترمینال MetaTrader 5 را باز کن** و مطمئن شو به حسابت لاگین است (حساب دمو هم کاملاً کافی است — برای گرفتن داده لازم نیست پول داشته باشی)

3. فایل `config.yaml` را با Notepad باز کن و خط اول را تغییر بده:
   ```yaml
   data_source: mt5
   ```
   و فایل را ذخیره کن.

4. اجرا:
   ```
   python main.py
   ```
   (یا بدون ویرایش config: `python main.py --source mt5`)

### اگر نمادی پیدا نشد

بعضی بروکرها به نام نمادها پسوند می‌زنند. در MT5 روی Market Watch نگاه کن نام دقیق نمادها چیست:

- اگر همه نمادها پسوند دارند (مثلاً `EURUSD.m` یا `EURUSDm`)، در `config.yaml` بخش `mt5` را تنظیم کن:
  ```yaml
  mt5:
    symbol_suffix: ".m"     # یا "m" — دقیقاً همان چیزی که بروکرت استفاده می‌کند
  ```
- اگر فقط نام طلا فرق دارد (مثلاً `GOLD` یا `XAUUSD.a`)، همان یک نماد را در `config.yaml` ویرایش کن:
  ```yaml
  - name: XAUUSD
    ...
    mt5: GOLD        # نام دقیق نزد بروکر تو
  ```

## 🔧 جدول رفع اشکال

| مشکل | راه‌حل |
|---|---|
| `'python' is not recognized` | پایتون را با تیک **Add to PATH** دوباره نصب کن، یا از `py main.py` استفاده کن |
| متن فارسی در کنسول به‌هم‌ریخته | برنامه خودش خروجی را UTF-8 می‌کند؛ اگر هنوز خراب بود از **PowerShell** یا **Windows Terminal** (رایگان از Microsoft Store) استفاده کن، نه cmd قدیمی |
| ایموجی‌ها مربع نشان داده می‌شوند | فقط مشکل نمایشی است — Windows Terminal نصب کن |
| `MetaTrader5` نصب نمی‌شود | فقط ویندوز ۶۴ بیتی + پایتون ۶۴ بیتی؛ `python -c "import platform; print(platform.architecture())"` باید `64bit` باشد |
| خطای «اتصال به MT5 ناموفق» | ترمینال MT5 باید **باز و لاگین** باشد؛ بعدش دوباره اجرا کن |
| خطای «ترمینال به سرور بروکر وصل نیست» | اینترنت و لاگین حساب را در MT5 چک کن (پایین سمت راست ترمینال باید پینگ نشان دهد) |
| Yahoo داده نمی‌دهد | طبیعی است (محدودیت منطقه‌ای) — از منبع `mt5` استفاده کن |
| `pip` کار نمی‌کند | `python -m pip install -r requirements.txt` را امتحان کن |
