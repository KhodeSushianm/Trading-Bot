# 🖥️ راهنمای پنل گرافیکی و نصب برنامه (ODIN Assistant)

این راهنما دو مسیر دارد: **نصب‌کنندهٔ رسمی از ریلیز گیت‌هاب** (پیشنهادی)،
**نسخهٔ پرتابل تک‌فایلی** یا **اجرای سورس با پایتون**.

> 📌 **یادداشت کامل هر نسخه در [`CHANGELOG.md`](../CHANGELOG.md) است** — همان فایلی
> که CI یادداشت Release را از آن می‌خواند. اینجا فقط آنچه **تجربهٔ کاربریِ پنل
> ویندوز** را عوض کرده می‌آید، نه فهرست کامل تغییرات.

## 🅰️ مسیر پیشنهادی: نصب‌کنندهٔ رسمی (setup.exe)

1. برو به صفحه ریپازیتوری ← تب **Releases** (سمت راست صفحه)
2. آخرین نسخه را باز کن و فایل `ODINAssistant-vX.X.X-windows-setup.exe` را دانلود کن
3. دابل‌کلیک کن و مراحل نصب را برو:
   - ⚠️ **هشدار آبی SmartScreen** ممکن است ظاهر شود (چون فایل امضای دیجیتال ندارد):
     روی **More info** و سپس **Run anyway** کلیک کن. کاملاً طبیعی و بی‌خطر است.
   - پیش‌فرض «فقط برای من» است (بدون UAC، داخل AppData)؛ اگر «نصب برای همهٔ کاربران» را انتخاب کنی Program Files استفاده می‌شود و ویندوز رمز مدیر می‌خواهد
   - تیک آیکون دسکتاپ اختیاری است؛ منوی استارت همیشه ساخته می‌شود
4. بعد از نصب، از منوی استارت **ODIN Assistant** را اجرا کن.
   - 🗂️ برنامهٔ نصب‌شده داده‌هایش را در پوشهٔ استاندارد ویندوز می‌گذارد:
     `%APPDATA%\ODIN Assistant` (یعنی `C:\Users\<نام‌کاربری>\AppData\Roaming\ODIN Assistant`)
     شامل `config.yaml`، `config.local.yaml` (توکن تلگرام)، `logs\` (ژورنال و لاگ‌ها) و `data\cache\`
   - داخل پنل، دکمهٔ **«پوشهٔ داده‌ها»** در صفحهٔ تنظیمات، همین مسیر را باز می‌کند
5. بخش **تلگرام** را تنظیم کن (راهنمای پایین) و دکمه **«▶ شروع ربات»** را بزن.

> 🧳 **نسخهٔ پرتابل** (`ODINAssistant-vX.X.X-windows.exe` در همان ریلیز) هم هست:
> در هر پوشه‌ای بگذاری، همهٔ داده‌ها **کنار خودش** ساخته می‌شوند (مثل نسخه‌های قدیمی).
> اگر پوشهٔ پرتابل قدیمی (≤ v0.7.2) داری، فقط EXE جدید را همان‌جا کپی کن —
> تنظیمات و ژورنالت خودکار حفظ می‌شوند. برای اجبار به حالت پرتابل حتی داخل
> Program Files، یک فایل خالی به نام `.portable` کنار EXE بساز.

> 🧭 **مهاجرت از پرتابل قدیمی به نسخهٔ نصب‌شده:** بعد از نصب، دو فایل را از پوشهٔ
> قدیمی به `%APPDATA%\ODIN Assistant` کپی کن: `config.local.yaml` و `logs\signals.jsonl`.

> 🗑️ **حذف برنامه:** Settings → Apps → ODIN Assistant → Uninstall.
> داده‌های شما (تنظیمات/ژورنال) عمداً در `%APPDATA%` نگه داشته می‌شوند؛
> اگر می‌خواهی همه‌چیز پاک شود، پوشهٔ `ODIN Assistant` را از AppData دستی حذف کن.

## 🅱️ مسیر سورس (برای توسعه)

```
pip install -r requirements.txt
python panel.py
```

ساخت EXE روی کامپیوتر خودت (اختیاری — ریلیز رسمی همان است):
```
build_exe.bat        ← دابل‌کلیک کن، همه‌چیز خودکار است
```
خروجی: `dist\ODINAssistant.exe` + (اگر Inno Setup نصب باشد)
`installer\Output\ODINAssistant-vX.X.X-windows-setup.exe`

## 📱 تنظیم تلگرام (یک‌بار، ۳ دقیقه)

1. در تلگرام، بات رسمی **`@BotFather`** را باز کن و پیام بده: `/newbot`
2. یک **نام** و یک **نام‌کاربری** (باید به `bot` ختم شود، مثل `MyForexSignalBot`) انتخاب کن
3. BotFather یک **توکن** می‌دهد (چیزی شبیه `7123456789:AAF...`) — کپی‌اش کن
4. در پنل: توکن را در کادر «توکن بات» بچسبان (با Enter یا کلیک بیرون، خودکار ذخیره می‌شود)
5. حالا به **بات خودت** (نه BotFather) پیام بده: `/start`
6. در پنل دکمه **«📥 گرفتن خودکار شناسه»** را بزن — شناسه چت خودکار پر و ذخیره می‌شود
7. دکمه **«✅ ارسال پیام تست»** — اگر پیام روی گوشی‌ات آمد، همه‌چیز درست است 🎉
8. تیک **«گزارش‌ها به تلگرام ارسال شود»** را روشن نگه دار

> 🔒 توکن و شناسه چت در فایل `config.local.yaml` کنار برنامه ذخیره می‌شوند که
> **هرگز به گیت‌هاب ارسال نمی‌شود** (در `.gitignore` هست). پس با خیال راحت پوشه برنامه را بکاپ بگیر،
> ولی اگر روزی پوشه پروژه را به کسی دادی، اول `config.local.yaml` را پاک کن.

## 🔤 فونت ایران‌سنس (IRANSans)

- فونت پیش‌فرض پنل: **وزیرمتن (Vazirmatn)** — فونت آزاد و زیبای فارسی که همراه برنامه می‌آید.
- اگر فایل ایران‌سنس را داری (نسخه دارای مجوز): یک پوشه `fonts` **کنار EXE** بساز و
  فایل‌های `.ttf` آن (مثل `IRANSansWeb.ttf` یا `IRANSansX-Regular.ttf`) را داخلش بگذار
  و برنامه را باز کن — پنل **خودکار** ایران‌سنس را تشخیص می‌دهد و استفاده می‌کند.
- چرا ایران‌سنس همراه EXE نیست؟ چون فونت تجاری است و توزیع عمومی آن بدون مجوز مجاز نیست؛
  ولی برنامه طوری ساخته شده که فونت تو را اولویت اول قرار می‌دهد.

## 🧩 اجزای پنل

رابط یک **پنل شیشه‌ای** روی پس‌زمینهٔ خاکستری محو است: هدر با سلام بزرگ و دکمه‌های
دایره‌ای، **سایدبار کارت شناور** با آیتم فعال = پیِل مشکی، و ۷ صفحه.
تم کاملاً مونوکروم است؛ فقط سبز برای خرید/موفقیت و قرمز برای فروش/وتو.
جزئیات کامل طراحی در [`ui-design-fa.md`](ui-design-fa.md).

| بخش | کار |
|---|---|
| 🖼 Splash | کارت مشکی برند: «خوش اومدی …» + لوگو + خط پیشرفت، سپس محو می‌شود (با `ui.splash: false` یا `--no-splash` غیرفعال است) |
| هدر | لوگو + نام برنامه + چیپ «خوش اومدی {نام}» + ساعت |
| سایدبار شناور | ۷ آیتم با آیکون برداری؛ آیتم فعال = پیِل مشکی؛ آیتمی که محتوای جدید گرفته ۶ ثانیه قرمز می‌درخشد |
| صفحهٔ **داشبورد** | کارت مشکی «نمای کلی» (قرص وضعیت + اعداد بزرگ + کاشی‌ها) · نمودار خطی قدرت ارزها · حلقهٔ آمادگی سیگنال · سیگنال‌های اخیر + کارت خط‌چین · چک‌لیست موتورها · رویدادهای پیش‌رو به‌شکل کارت مشکی |
| 🟢 قرص وضعیت | در حال اجرا (نقطهٔ تپنده سبز) / متوقف / در حال تحلیل / خطا |
| 🚫 ردیف وتو | آیا الان وتوی خبری فعال است؟ (کدام نمادها و تا کی) |
| 🏦 ردیف فاندامنتال | وضعیت تقویم اقتصادی + تعداد خبرهای رصدشده + تعداد هشدارهای ارسال‌شده |
| 🎯 ردیف سیگنال | سیگنال‌های آخرین چرخه + مجموع سیگنال‌ها + چند مورد تکراری و ارسال‌نشد |
| 🌅 بریفینگ بعدی | آخرین بریفینگ و ساعت بریفینگ بعدی (UTC) |
| ▶ شروع / ⏹ توقف / 🔄 یک‌بار | کنترل حلقه تحلیل خودکار (هر ۱۵ دقیقه) یا اجرای فوری یک تحلیل |
| 🌅 بریفینگ صبحگاهی | ساخت و ارسال فوری بریفینگ (بدون انتظار برای ساعت زمان‌بندی‌شده) |
| 📱 کارت تلگرام | توکن، شناسه چت (خودکار)، ارسال تست، روشن/خاموش کردن ارسال گزارش |
| تب «🟢 گزارش زنده» | همه رویدادها لحظه‌به‌لحظه (مثل یک کنسول ولی داخل برنامه) |
| تب «📄 آخرین گزارش کامل» | متن کامل آخرین گزارش تحلیل ۷ نماد (تکنیکال + تاییدیه TV + تقویم + اخبار) |
| تب «🏦 تقویم و اخبار» | فقط بخش فاندامنتال: رویدادهای پیش‌رو با تفسیر فارسی + فهرست خبرهای امتیازدهی‌شده |
| تب «🌅 بریفینگ صبحگاهی» | آخرین بریفینگ (تقویم پیش‌رو، پنجره‌های ممنوعه، جهت مورد انتظار هر نماد) |
| صفحهٔ **سیگنال‌ها** | متن کامل سیگنال‌ها: ورود، حد ضرر، هدف، نسبت R:R و **همهٔ دلایل** (حتی مدارکی که امتیاز نگرفتند) |
| صفحهٔ **گزارش کامل** | گزارش دوره‌ای کامل |
| صفحهٔ **تنظیمات** | نسخهٔ کامل (آینهٔ اندروید): شخصی‌سازی، داور، وتوها، موتورها، حلقه/گزارش‌ها، ظاهر، تلگرام، داده‌ها و فایل‌ها — پایین‌تر بخش مستقل دارد |
| ⚙️ / 📂 | باز کردن فایل تنظیمات و پوشه لاگ‌ها (گزارش‌ها در `logs/reports.log` و بریفینگ‌ها در `logs/briefings.log` بایگانی می‌شوند) |

## ⚙️ صفحهٔ تنظیمات — نسخهٔ کامل (آینهٔ اندروید)

از نسخهٔ ۰٫۸٫۱ صفحهٔ تنظیمات همان امکانات صفحهٔ تنظیمات نسخهٔ اندروید را دارد
(و بیشتر). هر تغییر **فوری** ذخیره می‌شود و از چرخهٔ تحلیل بعدی اثر می‌کند — بدون
نیاز به بستن برنامه:

| کارت | محتوا |
|---|---|
| **شخصی‌سازی** | نام نمایشی (در «سلام …!» هدر، آواتار و Splash) — فوری در هدر اعمال می‌شود |
| **داور امتیازدهی** | روشن/خاموش‌کردن داور، آستانهٔ صدور سیگنال (۴ تا ۱۰)، حداکثر سیگنال هر چرخه (۱ تا ۵) |
| **دروازه‌های وتو** | شش وتو (بازار بسته، رویداد پراثر، تضاد تایم‌فریم، بازار بی‌روند، جهش نوسان، خبر فوری) هرکدام جدا روشن/خاموش می‌شود |
| **موتورها** | تقویم اقتصادی، هشدار رویداد نزدیک، موتور اخبار، تأییدیهٔ تریدینگ‌ویو |
| **حلقهٔ خودکار و گزارش‌ها** | فاصلهٔ تحلیل خودکار (۵ تا ۱۲۰ دقیقه)، بریفینگ صبحگاهی، ژورنال/کارنامه، قانون محافظه‌کارانهٔ «هر دو لمس» |
| **ظاهر** | صفحهٔ خوش‌آمدگویی (از اجرای بعدی) و انیمیشن‌ها (فوری) |
| **تلگرام** | توکن، شناسه چت خودکار، پیام تست، روشن/خاموش ارسال |
| **داده‌ها** | پاک‌کردن کش تقویم + **بازنشانی همهٔ تنظیمات** (تلگرام/ژورنال پاک نمی‌شوند) |
| **فایل‌ها / درباره** | مسیرهای داده، بازکردن config.yaml، نسخه و هشدار غیرخودکار بودن |

**کجا ذخیره می‌شود؟** همهٔ این‌ها در `config.local.yaml` داخل پوشهٔ داده‌ها
(بیرون از گیت) نوشته می‌شوند و بر `config.yaml` اولویت دارند — همان رفتاری که
نسخهٔ اندروید با حافظهٔ داخلی خودش دارد. ویرایش دستی `config.yaml` هم هنوز
ممکن است؛ در آن صورت مقادیر پنل (اگر ذخیره شده باشند) برنده‌اند.

**بازنشانی** فقط کلیدهای مدیریت‌شدهٔ پنل را از فایل محلی حذف می‌کند؛ توکن
تلگرام و ژورنال دست‌نخورده می‌مانند.

## ❓ پرسش‌های متداول

**اگر اینترنت قطع باشد چه؟** چرخه تحلیل با خطا ثبت می‌شود، چرخه بعدی دوباره تلاش می‌کند؛ برنامه نمی‌افتد.
**اگر تریدینگ‌ویو در دسترس نباشد؟** گزارش بدون تاییدیه TV چاپ می‌شود (بقیه بخش‌ها سالم).
**اگر تقویم اقتصادی در دسترس نباشد؟** از کش محلی (`data\cache\calendar.json`) استفاده می‌شود؛ اگر کش هم
نباشد، گزارش با هشدار «تقویم در دسترس نبود» چاپ می‌شود و **وتوی خبری اعمال نمی‌شود** —
یعنی تحلیل فقط تکنیکال است. در این حالت خودت تقویم را دستی چک کن.
**شنبه/یکشنبه چرا تقویم خالی است؟** فید ForexFactory فقط هفتهٔ جاری (شنبه تا جمعه) را پوشش می‌دهد.
در روزهای پایانی هفته رویداد آینده‌ای در آن نیست و برنامه همین را صادقانه می‌گوید —
«رویدادی نیست» با «داده خراب است» فرق دارد و در گزارش تفکیک می‌شود.
**چرا یک خبر جهت نگرفت؟** سه حالت: (۱) سوژهٔ جمله داراییِ خارج از پوشش ماست (نقره، بیت‌کوین، اوراق)،
(۲) مقاله «جمع‌بندی هفته» است و چندجهتی، (۳) متن هم سیگنال صعودی دارد هم نزولی.
در هر سه حالت برنامه **حدس نمی‌زند** و جهت را خالی می‌گذارد.
**اسم من در Splash از کجا می‌آید؟** از صفحهٔ **تنظیمات → شخصی‌سازی** (نام نمایشی)؛
همان نام در `config.local.yaml` بخش `ui.user_name` ذخیره می‌شود. اگر از پنل ست
ننشده باشد، مقدار `config.yaml` (بخش `ui.user_name`) استفاده می‌شود. Splash
(`ui.splash`) و انیمیشن‌ها (`ui.animations`) هم از کارت «ظاهر» همان صفحه خاموش/روشن می‌شوند.
**تم تیره هم دارد؟** فعلاً نه — تم فعلی روشنِ شیشه‌ای است (انتخاب طراحی بر اساس رفرنس).
همهٔ توکن‌ها در `src/ui/theme.py` متمرکزند، بنابراین افزودن تم تیره در آینده کار
کوچکی است ولی الان پیاده نشده.
**کارنامه از کجا می‌آید؟** از `logs/signals.jsonl`: هر سیگنال ثبت می‌شود و نتیجه‌اش
به‌صورت خودکار از روی کندل‌ها تعیین می‌شود. گزارش هفتگی به‌صورت خودکار یکشنبه‌ها
۲۰:۰۰ UTC و خلاصهٔ شبانه هر شب ۲۱:۳۰ UTC ارسال می‌شود (قابل تغییر در بخش
`journal` تنظیمات). جزئیات: [`step4-journal-stats-fa.md`](step4-journal-stats-fa.md).
**چطور ساعت بریفینگ را عوض کنم؟** در `config.yaml` بخش `briefing.times_utc` — مثلاً `["06:30", "12:00"]`.
**چرا سیگنال نمی‌گیرم؟** سه حالت دارد و همه در بخش «⚖️ داور امتیازدهی» در گزارش نوشته می‌شود:
(۱) **وتو** — بازار بسته، رویداد پراثر نزدیک، تضاد تایم‌فریم، بازار رنج، جهش نوسان یا خبر فوری؛
(۲) **امتیاز ناکافی** — زیر ۷ از ۱۱؛ آن‌وقت فهرست «✅ داشت / ➖ نداشت» را می‌بینی؛
(۳) **ستاپ نبود** — خودِ تحلیل تکنیکال الگویی پیدا نکرده.
«سیگنال ندادن» خرابی نیست؛ وعدهٔ سیستم این است که سیگنال **بدون پشتوانه** ندهد.
**یک سیگنال تکراری چرا دوباره نیامد؟** تا ۱۸۰ دقیقه (`judge.resend_cooldown_minutes`)
همان سیگنال دوباره به تلگرام نمی‌رود، مگر اینکه امتیازش حداقل ۲ واحد بهتر شده باشد.
در پنل همیشه نمایش داده می‌شود و در لاگ هم نوشته می‌شود چرا ارسال نشد.
**چطور بفهمم داور در روز کاری چه می‌کرد؟** با خط فرمان: `python main.py --as-of "2026-09-17 14:00"`.
در این حالت هیچ پیامی به تلگرام نمی‌رود و بالای گزارش بنر «حالت شبیه‌سازی» چاپ می‌شود.
**سیگنال‌ها کجا ذخیره می‌شوند؟** در `logs/signals.jsonl` (هر سیگنال یک خط JSON، شامل
ورود/حد ضرر/هدف/امتیاز/مدارک). مرحلهٔ ۴ نتیجهٔ هرکدام را پیگیری و آمار دقت را می‌سازد.
**هشدار رویداد تکراری می‌گیرم؟** نه. فهرست هشدارهای ارسال‌شده در `data\cache\sent_alerts.json`
نگه داشته می‌شود و هر رویداد فقط یک بار هشدار می‌دهد (حتی اگر برنامه را ببندی و باز کنی).
**برنامه را ببندم، تحلیل‌ها می‌ایستند؟** بله — حلقه داخل خود پنل اجرا می‌شود. (خاموش‌بودن کامپیوتر هم همین‌طور.)
**چطور فاصله تحلیل‌ها را عوض کنم؟** در `config.yaml` مقدار `loop.interval_minutes`.
**دو بار پنل را باز کردم؟** برنامه اجازه اجرای همزمان نمی‌دهد (پیام «از قبل در حال اجراست»).
**اگر `python panel.py` را در cmd اجرا کنم و متن فارسی به‌هم بریزد؟** برنامه خودش کنسول را
روی UTF-8 می‌گذارد (`app_paths.fix_console_encoding()`). اگر باز هم به‌هم ریخته دیدی،
یک‌بار `chcp 65001` را در cmd اجرا کن و فونت کنسول را روی **Consolas** یا **Cascadia Mono** بگذار
(فونت پیش‌فرض قدیمی cmd، گلیف فارسی و ایموجی ندارد — این مشکل نمایش است، نه برنامه).
**EXE آنتی‌ویروس/SmartScreen هشدار می‌دهد؟** برای برنامه‌های PyInstaller بدون امضای دیجیتال رایج و بی‌خطر است؛
در SmartScreen: More info → Run anyway. (اگر آنتی‌ویروس شخصی فایل را قرنطینه کرد، استثنا بده.)
