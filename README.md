# 🤖 Trading-Bot — دستیار تحلیل و سیگنال فارکس

![داشبورد](docs/images/panel-dashboard.png)

یک سیستم **غیرخودکار** تحلیل بازار فارکس و طلا که روی کامپیوتر شخصی (ویندوز) اجرا می‌شود:
بازار را تحلیل می‌کند (تکنیکال + فاندامنتال + اخبار)، به هر فرصت معاملاتی **امتیاز پشتوانه** می‌دهد
و سیگنال‌های معتبر را با **دلایل کامل و به زبان ساده فارسی** روی **تلگرام** ارسال می‌کند.

> ⚠️ این سیستم هیچ معامله‌ای را به‌صورت خودکار اجرا نمی‌کند. تصمیم نهایی همیشه با کاربر است.

---

## ✨ قابلیت‌ها

- 🖥️ **پنل گرافیکی ویندوزی (EXE آماده در GitHub Releases)** — بدون ترمینال و CMD؛ فقط دابل‌کلیک
- 🎨 **رابط مونوکروم تاریک به زبان Fluent ویندوز ۱۱** — داشبورد، ریل ناوبری با آیکون برداری،
  انیمیشن ظریف، و Splash «خوش اومدی …» ([سند طراحی](docs/ui-design-fa.md))
- 📱 **گزارش‌ها مستقیم روی تلگرام** — بریفینگ، سیگنال، هشدارها؛ تنظیم توکن داخل خود پنل
- 🔤 **فونت فارسی وزیرمتن** (و پشتیبانی خودکار از ایران‌سنس اگر فایلش را بگذارید)

- 📈 **تحلیل تکنیکال چندتایم‌فریمی** — روند (EMA)، قدرت روند (ADX)، مومنتوم (RSI)، نوسان (ATR)، سطوح حمایت/مقاومت، قدرت ارزها
- 🏦 **تحلیل فاندامنتال** — تقویم اقتصادی (ForexFactory) با عنوان و تفسیر فارسی، شناسایی رویدادهای پراثر، **وتوی خودکار سیگنال** نزدیک اخبار مهم
- 🚨 **هشدار رویداد** — ۳۰ دقیقه قبل از هر خبر پراثر، روی تلگرام (هر رویداد فقط یک بار)
- 🌅 **بریفینگ صبحگاهی** — هر روز قبل از باز شدن لندن: تقویم پیش‌رو، پنجره‌های ممنوعهٔ ورود، تیترهای بازار و جهت مورد انتظار هر نماد
- 📰 **رصد اخبار** — فیدهای RSS فارکس با **امتیاز اهمیت ۰ تا ۶** و **جهت اثر روی هر ارز** (↑/↓)
- ⚖️ **داور امتیازدهی (Confluence)** — سیگنال فقط با پشتوانهٔ قوی (امتیاز ≥ ۷ از ۱۱) و عبور از **۷ دروازهٔ وتو**
- 🎯 **سیگنال کامل با دلایل** — ورود، حد ضرر (از روی سطح کلیدی + ATR)، هدف با نسبت ۱:۲، و فهرست **مدارکی که امتیاز نگرفتند**
- 🚫 **ضداسپم** — یک ستاپ چندساعته فقط یک بار به تلگرام می‌رود (مگر امتیازش واقعاً بهتر شود)
- 🧪 **حالت شبیه‌سازی** — `--as-of "2026-09-17 14:00"` تا منطق داور را در روز کاری ببینی (بدون ارسال به تلگرام)
- 📱 **بات تلگرام** — بریفینگ صبحگاهی، سیگنال زنده با دلایل، هشدار رویدادها، خلاصه شبانه
- 📔 **ژورنال سیگنال** — ثبت هر سیگنال و پیگیری خودکار نتیجه + گزارش هفتگی دقت (حلقه صداقت)
- 🔍 **تاییدیه تریدینگ‌ویو** — امتیاز تکنیکال رسمی TradingView کنار تحلیل خودمان (مدرک متقابل، بدون لاگین)
- 💰 **هزینه: صفر** — همهٔ داده‌ها از منابع وب رایگان و **بدون کلید API** (Yahoo Finance اصلی، Twelve Data زاپاس اختیاری، ForexFactory، RSS)؛ بدون سرور و **بدون وابستگی به متاتریدر**

## 🚀 شروع کار (دو مسیر)

**مسیر پیشنهادی — EXE آماده:**
1. تب **Releases** در صفحه ریپازیتوری ← دانلود `ForexAssistant-...-windows.exe`
2. گذاشتن در پوشه اختصاصی (مثلاً `Desktop\ForexAssistant`) و دابل‌کلیک
3. تنظیم تلگرام داخل پنل (راهنما: [docs/panel-guide-fa.md](docs/panel-guide-fa.md)) ← «▶ شروع ربات»

**مسیر سورس (توسعه):**
```bash
pip install -r requirements.txt
python panel.py                  # پنل گرافیکی (مسیر اصلی استفاده)
python main.py                   # یک چرخهٔ کامل در کنسول
python main.py --briefing        # 🌅 فقط بریفینگ صبحگاهی
python main.py --alerts --dry-run# 🚨 پیش‌نمایش هشدارهای رویداد (بدون ارسال)
python main.py --signals         # 🎯 فقط سیگنال‌های صادرشده
python main.py --as-of "2026-09-17 14:00"   # 🧪 شبیه‌سازی داور در یک زمان فرضی
python main.py --no-fundamental  # فقط تکنیکال (تقویم و اخبار خاموش)
python main.py --selftest        # خودآزمون بدون اینترنت
```

> 💡 `--as-of` برای وقتی است که بازار بسته است (آخر هفته) ولی می‌خواهی ببینی
> داور در یک روز کاری چه می‌کرد. در این حالت **هیچ سیگنالی به تلگرام نمی‌رود**
> و در ژورنال ثبت نمی‌شود، و بالای گزارش بنر «حالت شبیه‌سازی» چاپ می‌شود.

> 💡 پروژه هیچ وابستگی به متاتریدر ندارد — فقط اینترنت لازم است.
> EXE به‌صورت خودکار توسط GitHub Actions روی ویندوز ساخته و در Releases منتشر می‌شود.

### 🧪 تست و CI

| فرمان | چه می‌سنجد |
|---|---|
| `python main.py --selftest` | پارس تقویم، قطبیت شاخص‌ها، ۹ حالت جهت‌دهی اخبار، **مسیر سیگنال، ۶ وتو، ریاضی SL/TP، سقف تعداد سیگنال، ژورنال**، کدگذاری کنسول ویندوز |
| `python panel.py --selftest` | پنل گرافیکی (offscreen) + ۵ تب + منطق فاندامنتال و داور |
| `python tests/check_config.py` | کامل و معتبر بودن `config.yaml` (شامل ۲۳ بررسی روی `judge.*`) |
| `python tests/manual/test_judge.py` | تست جامع داور در ۹ بخش (آفلاین و قطعی) |

هر سه روی **هر push** در GitHub Actions اجرا می‌شوند (جاب `test`، بدون ساخت EXE).
ساخت و انتشار EXE فقط روی تگ `v*` یا اجرای دستی workflow انجام می‌شود.

## ⚠️ سلب مسئولیت

- این پروژه یک ابزار **کمک‌تحلیلی** است، نه مشاور مالی. هیچ سیستمی سود را تضمین نمی‌کند.
- معاملات فارکس ریسک بالایی دارد؛ فقط با سرمایه‌ای معامله کنید که تحمل از دست دادنش را دارید.
- خروجی سیستم (سیگنال‌ها) صرفاً پیشنهاد است و مسئولیت هر معامله با خود کاربر است.
