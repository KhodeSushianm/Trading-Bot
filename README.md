# 🤖 Trading-Bot — دستیار تحلیل و سیگنال فارکس

یک سیستم **غیرخودکار** تحلیل بازار فارکس و طلا که روی کامپیوتر شخصی (ویندوز) اجرا می‌شود:
بازار را تحلیل می‌کند (تکنیکال + فاندامنتال + اخبار)، به هر فرصت معاملاتی **امتیاز پشتوانه** می‌دهد
و سیگنال‌های معتبر را با **دلایل کامل و به زبان ساده فارسی** روی **تلگرام** ارسال می‌کند.

> ⚠️ این سیستم هیچ معامله‌ای را به‌صورت خودکار اجرا نمی‌کند. تصمیم نهایی همیشه با کاربر است.

---

## ✨ قابلیت‌ها

- 📈 **تحلیل تکنیکال چندتایم‌فریمی** — روند (EMA)، قدرت روند (ADX)، مومنتوم (RSI)، نوسان (ATR)، سطوح حمایت/مقاومت، قدرت ارزها
- 🏦 **تحلیل فاندامنتال** — تقویم اقتصادی (ForexFactory)، شناسایی رویدادهای پراثر، وتوی خودکار سیگنال نزدیک اخبار مهم
- 📰 **رصد اخبار** — فیدهای RSS تخصصی فارکس با امتیازدهی جهت‌دار
- ⚖️ **داور امتیازدهی (Confluence)** — سیگنال فقط با پشتوانه قوی (امتیاز ≥ ۷ از ۱۰) و عبور از دروازه‌های وتو
- 📱 **بات تلگرام** — بریفینگ صبحگاهی، سیگنال زنده با دلایل، هشدار رویدادها، خلاصه شبانه
- 📔 **ژورنال سیگنال** — ثبت هر سیگنال و پیگیری خودکار نتیجه + گزارش هفتگی دقت (حلقه صداقت)
- 💰 **هزینه: صفر** — داده از MT5 خود کاربر (کیفیت بالا، رایگان) و منابع رایگان؛ بدون نیاز به سرور

## 🎯 نمادهای تحت پوشش

`EURUSD` · `GBPUSD` · `USDJPY` · `USDCAD` · `AUDUSD` · `USDCHF` · `XAUUSD (طلا)`

## 📁 ساختار ریپازیتوری

```
Trading-Bot/
├── README.md              ← همین فایل
├── config.yaml            ← پیکربندی (نمادها، آستانه‌ها، منبع داده) — قابل ویرایش
├── main.py                ← نقطه ورود: python main.py [--source mt5|yahoo]
├── requirements.txt
├── docs/                  ← مستندات طراحی
└── src/
    ├── config.py          ← بارگذاری پیکربندی
    ├── data/              ← منابع داده
    │   ├── base.py        ←   رابط مشترک (MarketData)
    │   ├── mt5_source.py  ←   MetaTrader 5 (نسخه نهایی — ویندوز)
    │   └── yahoo_source.py←   Yahoo Finance (تست و توسعه)
    ├── analysis/
    │   ├── indicators.py  ← EMA, RSI, ATR, ADX, سطوح حمایت/مقاومت
    │   ├── technical.py   ← تحلیل چندتایم‌فریمی → SymbolAnalysis
    │   └── strength.py    ← سنجه قدرت ارزها
    └── report/
        └── console.py     ← گزارش فارسی (تلگرام در مرحله ۴)
```

## 🚀 اجرای سریع (فعلاً برای تست)

```bash
pip install -r requirements.txt
python main.py                # با منبع Yahoo (پیش‌فرض config.yaml)
python main.py --source mt5   # روی ویندوز با MT5 باز (بعد از pip install MetaTrader5)
```

## ⚠️ سلب مسئولیت

- این پروژه یک ابزار **کمک‌تحلیلی** است، نه مشاور مالی. هیچ سیستمی سود را تضمین نمی‌کند.
- معاملات فارکس ریسک بالایی دارد؛ فقط با سرمایه‌ای معامله کنید که تحمل از دست دادنش را دارید.
- خروجی سیستم (سیگنال‌ها) صرفاً پیشنهاد است و مسئولیت هر معامله با خود کاربر است.
